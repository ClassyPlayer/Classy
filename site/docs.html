Wi-Fi

WebDAV Sync

Copies music from a WebDAV server (for example a Synology NAS or Nextcloud) to the player over Wi-Fi. The copy goes in one direction only. Classy does not change the files on the server.

Open: Main menu → Settings → Library → WebDAV Sync. The row shows @ and the username, or Not Configured.

Set it up

  1. Select Server URL. Type the address of your music folder, for example https://192.168.1.10:5006/music.
  2. Select Username and type the username.
  3. Select Password and type the password.
  4. Select Test Connection. The screen shows Connected, or an error (Problems).
  • The address must start with http:// or https:// and have a host. Classy refuses an address with user:password@.
  • You can sync only the folders below the Server URL.
  • Test Connection and Sync Now need Wi-Fi. Without Wi-Fi, they open the Wi-Fi screen.

Set it up with a file

  1. Put a file classy_webdav.json in the top folder of the internal storage (the folder that holds Music). All three fields must have a value. 
    { "url": "https://192.168.1.10:5006/music", "user": "name", "password": "secret" }
  2. Open WebDAV Sync. Classy saves the settings and deletes the file.
  • A file that is not valid stays. The screen shows classy_webdav.json: invalid.
  • If Classy cannot delete the file, it does not use it. The screen shows classy_webdav.json: cannot delete it, delete it by hand.
  • During a sync, Classy does not read the file. Open WebDAV Sync again after the sync.
  • A different url is a new Server URL (Log Out / Reset).

Certificates

A certificate that Android trusts needs no step. Android 4.4 does not trust some newer authorities, for example Let's Encrypt. For such a certificate, a self-signed certificate, or a certificate for a different name, do these steps:

  1. Select Test Connection. The screen shows Check the certificate fingerprint, then Trust Certificate.
  2. Find the SHA-256 fingerprint of the server certificate, for example in the certificate details of a web browser.
  3. Compare it with the four lines below Certificate on the player.
  4. If they are the same, select Trust Certificate.
  • Classy then accepts this certificate with all host names, also an IP address.
  • When the certificate changes (for example after a renewal), do the steps again.
  • A new Server URL removes the trusted certificate.

http:// has no protection: each request sends the password in clear text, also from Auto Sync. Use https:// if the server has it.

Folders

Select Folders to see the folders of the Server URL. The row shows the number of ticked folders.

  • Push Center to open a folder. Hold Center to tick or untick it.
  • Push Center on This Folder (first row) to tick the open folder. Use it for a folder with only files.
  • A ticked folder includes all its sub-folders. To leave out one sub-folder, untick the parent and tick the other sub-folders.
  • You cannot tick one file.
  • At the next sync, Classy deletes the files of an unticked folder from the player.

Sync

Select Sync Now. The screen shows the progress. Push Back to cancel.

  • The sync downloads the new and changed files of the ticked folders. It deletes the files of unticked folders.
  • It copies all files, also covers and .lrc lyrics.
  • The files go to the Music folder of Save To, in the same folder tree. For example, …/music/Artist/Album/01.flac becomes Music/Artist/Album/01.flac.
  • A file is changed when its ETag changed. With no ETag, Classy compares the size and the date.
  • If the files do not fit, the sync stops before it downloads (Not enough space).
  • When files changed, the library scans again. This also occurs after a failed or cancelled sync.
  • Parallel Downloads: 1 to 4 files at the same time. The default, 1, is best for a weak Wi-Fi or NAS.
  • Last Synced shows the time of the last good sync, or Never. After a failed sync, Last sync failed and the error show below it.
  • Classy does not replace or delete the song that plays. The next sync does it.
  • Classy does not write over a file that it did not sync (for example from Jellyfin Sync). If that file has the size of the server file, Classy uses it as the synced copy. If not, Classy skips the server file.
  • A failed or cancelled download does not change the old file.
  • With no ticked folder, Sync Now asks before it deletes all synced files. If there are no synced files, it shows Select folders first.

Save To

  • Save To: Internal or SD Card. You cannot change it during a sync.
  • After a change, Move Synced Files shows the number of files on the other storage. Select it to move them. Classy does not download them again.
  • If you do not move them, they stay. Only a file that changed on the server goes to the new storage.
  • A move copies and checks each file, then deletes the old copy. The song that plays does not move: move again later.
  • On the SD card, Classy changes < > : " | ? * \ in names to _. It removes a dot or space at the end of a name. Two names that become the same use one file.

Auto Sync

With Auto Sync On, the player syncs when it is on Wi-Fi and charging, at most one time each hour.

  • It starts when Wi-Fi connects or when you connect the charger. If the hour is not complete, it starts at the end of the hour.
  • A failed sync also counts for the hour.
  • It downloads and deletes as Sync Now does. With no ticked folder, it does not delete the synced files.
  • It shows no progress, and you cannot cancel it. Its errors show below Last Synced.
  • It works only while the Classy app runs.

Deleted on NAS

When a synced file is not on the server, Classy keeps your copy and shows it in Deleted on NAS.

  • Push Center on a file to delete it. With two or more files, Delete All deletes all. Classy asks before each delete.
  • A file that comes back on the server goes off the list.
  • When a ticked folder is not on the server, its files also go on this list.
  • If a folder listing fails for a different reason, the sync stops. No file goes on the list.

Log Out / Reset

Log Out / Reset removes all WebDAV Sync settings: address, login, certificate, ticked folders, Auto Sync, Parallel Downloads, Save To and Last Synced.

  • The songs stay on the player. Classy does not track them, so no sync deletes them. To remove them, use a file manager.
  • A new Server URL removes the server settings: ticked folders, certificate and Last Synced. The songs stay.
  • The same address in a different spelling (for example with a / at the end) keeps all settings.
  • After a reset, a sync uses an old copy again if it has the path and size of the server file. Else it skips that server file. Delete unwanted old copies by hand.
  • You cannot do a reset or change the Server URL during a sync (Syncing...).

Problems

MessageWhat to do
Server unreachableCheck the Wi-Fi, the Server URL and the NAS.
Check username/passwordThe server refused the login (HTTP 401 or 403). Check the Username and the Password.
Certificate not trustedDo the steps in Certificates.
Not enough spaceThe message shows the necessary and the free space. Free some space, or tick fewer folders.
HTTP 404 on a folderThe folder is not on the server. A sync puts its files on Deleted on NAS.
HTTP 301 (or another 3xx)The server sends Classy to a different address. Classy does not follow it, to keep the password safe. Use the final address as the Server URL.
SD card not foundPut in a microSD card, or set Save To to Internal.
Cannot save the sync recordClassy cannot write webdav_ledger.json (for example, the storage is full). Nothing changed.
Too many folders (a loop on the server?)A ticked folder has more than 20,000 folders below it, or the server links back to a folder above it.

Limits

  • Basic authentication only. The app settings keep the password in plain text, and adb backup can copy it. Log Out / Reset or Clear Data removes it.
  • All files go to the Music folder. For audiobooks, use Jellyfin Sync.
  • A cancelled download starts again from the beginning.
  • A skipped file shows only in the log.
  • A download has no time limit. A very slow server can keep Auto Sync running.
  • A power loss can remove the sync record. Then Classy deletes nothing, but it does not track the synced files.

For developers

  • Code: app/src/main/java/com/themoon/y1/sync/webdav/ and controllers/sync/WebDavUiController.kt. SyncPlan holds the pure sync rules; WebDavSync runs a sync and owns the ledger.
  • Shared with Jellyfin Sync: MediaSyncProvider, the SyncLedger format and SyncLocks. The engine is its own and keys each file by its href.
  • Data: prefs webdav_sync; ledger webdav_ledger.json in the primary storage root.
  • Auto Sync: ClassyApplication.onCreate registers the receiver in code. A manifest receiver starts a second app process on Android 4.4.
  • A new text needs all seven language packs (scripts/check_translations.py --strict). Tests: app/src/test/java/com/themoon/y1/sync/webdav/.

Audiobooks

Audiobook Series Cover Flow

An optional Cover Flow for audiobooks: one cover for each series, and one cover for each book in a series. Classy makes it from your folders.

Turn it on

  1. Go to Main menu → Settings → Library → Audiobook Series Cover Flow (first row).
  2. Push Center to set it to On.
  3. Go to Main menu → Audiobooks → Series Cover Flow (second row). The status bar shows Audiobook Series.
  • The setting is Off by default. When it is Off, the Series Cover Flow row does not show.
  • Main menu → Settings → Menus → Main Menu Items can hide Audiobooks.

Books and series

Classy reads the Audiobooks folder on the internal storage and on the microSD card.

  • Each audio file directly in Audiobooks (also an .m4b file) is a book.
  • A folder with no sub-folders and not more than one .m4b file is a book.
  • A folder with two or more books is a series. In a series, each sub-folder and each .m4b file is a book. The other audio files are one book, Other.
  • A folder with only one book shows as that book.
  • Classy skips a folder that holds only one folder of books. Thus Audiobooks/Jellyfin/Author/Book (from Jellyfin Sync) shows as the series Author.
  • A folder whose only sub-folder holds only files is one book: Saga/Only Book is the book Only Book.
Audiobooks/
  Long Walk.m4b               a book
  Sea Stories/                a book (files only)
    01.mp3  02.mp3  …
  The Saga/                   a series of three books
    1 First Book/             a book
    2 Second Book/            a book
    Extra.m4b                 a book

After you add or move books, scan again: Main menu → Audiobooks → Scan Media Library (last row).

Sort order

LevelOrder
Top levelThe series that you played last. Then all books and series A–Z (upper and lower case are the same).
In a seriesThe book that you played last. Then by the first number in the name (up to 4 digits: Book 2 before Book 10), then A–Z. Names with no number come last.
In a bookBy folder (Disc 1 before Disc 2), then by file name (2 before 10). Track tags do not change the order.
  • The Cover Flow opens on the book or series that you played last.
  • The cover of a series is the cover of its first book (by number, then name).

Playback

  • Push Center on a series to open it. Push Center on a book to play it from its saved place.
  • Each book keeps its own file and place. Each series keeps the last book that you played in it.
  • If the saved file is not in the book, the book starts at its first file.
  • Continue (Main menu → Audiobooks → Continue, first row) plays the last audiobook from its saved place. Music does not change the last audiobook.
  • With the setting On, Continue plays all files of the book (its folder or .m4b). With the setting Off, it uses the album tag.
  • Audiobooks never shuffle.

Speed, chapters and sleep timer

While an audiobook plays, hold Center on Now Playing. The menu shows these three rows at the top, also with the setting Off.

RowWhat it does
Audiobook Speed1.0x (Normal), 1.2x (Fast), 1.5x (Faster) or 2.0x (Very Fast), for all audiobooks. Music and podcasts use Main menu → Settings → Playback → Playback Speed.
ChaptersThe chapters of the .m4b file: a row goes to that chapter. For a book of many files, a row plays that file from its start.
Sleep Timer5, 10, 15, 30, 45, 60, 90 or 120 minutes. At the end, the book pauses, Classy saves the place and the player powers off. Stop Sleep Timer cancels it.

For developers

  • Setting: Prefs.AUDIOBOOK_SERIES_COVER_FLOW (audiobook_series_cover_flow, default off).
  • Index: controllers/coverflow/AudiobookSeriesIndex.kt, made in one pass from the paths of the scanned library. Screen: ScreenState.AudiobookCoverFlow(seriesDirectory).
  • Saved places (app prefs): book_pos_<path>, audiobook_last_in_<folder>, audiobook_series_last_book_<series>, audiobook_series_last_played, last_played_audiobook_path, audiobook_speed.
  • Tests: app/src/test/java/com/themoon/y1/controllers/AudiobookSeriesIndexTest.kt.
